about=IB-Tool 3 is a QGIS plugin for the automated delineation of the Innenbereich - the coherently built-up part of a municipality as defined in Sec. 34 BauGB, described as an urban growth boundary in the international publication of the method - based on building footprints. It provides automated geospatial processing tools for urban planning and settlement analysis, implementing complex algorithms for clustering, density calculations, and minimum spanning tree (MST) analysis. Features include automated building footprint filtering, road network analysis, partition-based processing, footprint density calculation, gap and hole closing, and comprehensive input data validation. Input data: the building-footprint and road-network filtering is designed around German ATKIS function codes; other datasets with a compatible field/function-code scheme may work but are not officially supported. Dependencies: in addition to numpy (bundled with QGIS 3.40+), this plugin requires scipy and networkx. If QGIS reports them as missing on load, install them once into QGIS's Python environment: on Windows, open the OSGeo4W Shell and run "pip install scipy networkx"; on Linux/macOS, run the same command in a terminal where QGIS's own Python is active. Then restart QGIS. For more information see the project repository: https://github.com/IB-Tool/IB-Tool-3
